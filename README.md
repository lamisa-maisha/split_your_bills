# A bill splitter
Its a python command line tool which calculates bills and tip and splits the bill among friends.

## Features
- Evaluates the food items costs
- Adds tip percentage (user gets to choose amount)
- Divides the bill evenly among customers/ friends
- Shows total amount of bill, tip amount, total with tip and per person amount

## How to run
'''bash
python bill splitter.py
